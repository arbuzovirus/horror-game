# HorrorGame

A first-person PS1-style horror game in Godot 4.7: a five-storey Soviet stairwell you can't leave, and flat 17 on the top floor.

**Controls:** WASD walk, Shift run, mouse look, F flashlight, E interact/examine, Esc free the mouse.

**Play:** download `HorrorGame.exe` from the Releases page, or open the project in Godot 4.7.2 and press F5.

See [CREDITS.md](CREDITS.md) for the addon, textures and sounds used.
